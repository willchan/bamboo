# Bamboo 🎋

A personal tool for remembering the Chinese you look up, so you can actually say it next time.

Import a Gemini conversation, keep the few phrases worth learning, and practise them aloud for
five minutes a day. Mandarin and Cantonese. Extraction runs on a local LLM; scheduling uses FSRS.

See [CLAUDE.md](CLAUDE.md) and [docs/](docs/) for the product, design, and build plan.

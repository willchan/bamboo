# Bundled data

## `wordfreq-zh.ts`: Mandarin word frequencies

Used by the queue's frequency signal (docs/DESIGN.md §4.6). Generated by
`web/scripts/wordfreq-zh.py`; don't edit by hand.

- **Source:** [wordfreq](https://github.com/rspeer/wordfreq) 3.1.1 by Robyn Speer, the `large`
  Chinese list. It mixes subtitles (OpenSubtitles, SUBTLEX-CH), chat, the web and Wikipedia, so it
  reflects spoken Mandarin better than news-based lists.
- **Kept:** all-hanzi words with a Zipf frequency of 2.0 or more (about 108,000), rounded to a
  tenth. Zipf is log10 of occurrences per billion words: 5+ is everyday (谢谢), 3 is ordinary
  (奶瓶), below 2 is rare.
